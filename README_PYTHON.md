# CASE BATTLE HELPER // CYBERPUNK TERMINAL HUD ⚡

Киберпанк-терминал и аналитический помощник для стримов и кейс-батлов CS:2 на Python.

## 🎯 Возможности:
- **Live Feed**: Отображение последних открытий в реальном времени с градацией по редкости (Mil-Spec, Restricted, Classified, Covert, Special/★ Ножи), ценами и расчетом профита.
- **Analytics Engine**:
  * **SCORE (0-100)**: Псевдо-динамический индекс вероятности, реагирующий на серии дешевых предметов и дисперсию.
  * **MOMENTUM**: Статус рынка (`COLD`, `STABLE`, `HOT`, `OVERHEATED`).
  * **RTP Math**: Расчет реальной окупаемости (Return to Player) за скользящее окно последних N открытий.
- **Cyberpunk Terminal**: Поток системных логов, статус WSS-соединения (ping, пакеты), расчет энтропии и телеметрия.
- **Два режима отображения**:
  1. Продвинутый графический TUI на базе библиотеки `rich` (сетка, панели, цветовые градиенты).
  2. Автоматический fallback на стандартный ANSI-терминал при отсутствии внешних библиотек.

## 🚀 Инструкция по установке и запуску:

### 1. Требования:
- Python 3.8 или новее.

### 2. Установка зависимостей:
Откройте терминал / PowerShell в папке проекта:
```bash
pip install -r requirements.txt
```
*(Если pip не установлен, скрипт всё равно запустится в режиме встроенного ANSI-терминала!)*

### 3. Запуск:
```bash
python case_battle_helper.py
```
или на Linux/macOS:
```bash
python3 case_battle_helper.py
```

### 4. Использование на стримах (OBS / Streamlabs):
1. Запустите скрипт в отдельном окне терминала (например, Windows Terminal, iTerm2 или Alacritty).
2. Настройте в терминале шрифт `JetBrains Mono` или `Consolas` и темную тему.
3. В OBS добавьте источник: **"Захват окна"** (Window Capture) -> выберите окно терминала.
4. Добавьте фильтр кадрирования (Crop) или хромакей по желанию, чтобы расположить аналитический HUD поверх игры или веб-камеры.

### 5. Остановка:
Нажмите сочетание клавиш `Ctrl + C`.
